# OverRich – Smart Streetwear Fashion Website

Frontend for **OverRich**, a streetwear brand selling premium oversized T-shirts. Built as a single, dependency-light page (HTML, CSS and vanilla JavaScript) with AOS scroll animations.

## Features
- Home page with hero carousel, Diwali sale banner with countdown, collections, categories, trending and new-arrival sliders, smart size finder, limited-edition drop, lookbook, reviews and newsletter
- Dedicated pages: Shop (filters by collection, colour, size, fit, sleeve, design, finish, price), New arrivals, Trending, Limited edition, Collections, Lookbook, Custom design, Wishlist, Bag, My orders, My account
- 34 styles in 15 colours across 7 collections, with photo-style product renders (flat lay, back, hanger, folded, close-up)
- Sign-in / sign-up popup that resumes the action you started (add to bag, wishlist, reminders)
- One-page checkout with demo payments: UPI, card (OTP), net banking, wallets and cash on delivery
- Order confirmation with delivery tracker, order history with cancel and buy-again
- Light and dark themes, fully responsive down to phone width

## Run locally
Open `index.html` in a browser. No build step.

> Demo only: accounts, orders and payments are simulated and stored in the visitor's browser.
